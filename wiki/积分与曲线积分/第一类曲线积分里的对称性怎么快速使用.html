第一类曲线积分里的对称性怎么快速使用

  • WIKI
  • 积分与曲线积分
  • 第一类曲线积分里的对称性怎么快速使用

¶这个工具解决什么问题

有些第一类曲线积分不需要老老实实参数化到底，只要先看曲线的对称性和被积函数的奇偶性，就可以直接把积分化成一半，甚至直接判成 0 。

这张卡解决的是：

什么时候第一类曲线积分可以先看对称性
看完以后可以立刻得到什么

¶使用条件

  • 积分是第一类曲线积分，即形如
∫Lf(x,y)ds
  • 积分曲线 L 关于某条坐标轴对称
  • 被积函数对相应变量具有奇偶性

¶基本套路

  1. 先确认这是第一类曲线积分，不是第二类。
  2. 再看曲线 L 是否关于 x 轴或 y 轴对称。
  3. 最后看 f(x,y) 对相应变量是奇是偶。

¶典型形式

¶1. 曲线关于 y 轴对称

若 L 关于 y 轴对称，记 L1 为 L 在右半平面 x≥0 的部分，则

∫Lf(x,y)ds={2∫L1f(x,y)ds,f(−x,y)=f(x,y),0,f(−x,y)=−f(x,y).

也就是说：

  • 对 x 是偶函数，左右两半相同，积分变成两倍半边
  • 对 x 是奇函数，左右两半相消，积分直接为 0

¶2. 曲线关于 x 轴对称

若 L 关于 x 轴对称，记 L1 为 L 在上半平面 y≥0 的部分，则

∫Lf(x,y)ds={2∫L1f(x,y)ds,f(x,−y)=f(x,y),0,f(x,−y)=−f(x,y).

¶为什么有效

第一类曲线积分的核心是

标量×ds

这里的 ds 只记录弧长，不记录方向。

所以当曲线关于某条轴对称时，对称两点对应的小弧长相同；如果函数值也满足“相等”或“互为相反数”，那么整段积分就会分别表现为：

  • 相等：两边贡献相同，所以乘 2
  • 相反：两边贡献抵消，所以为 0

这和定积分里“对称区间 + 奇偶性”的逻辑是同一套结构，只不过这里的“区间对称”换成了“曲线对称”。

¶用例

  • 若 L 是关于 y 轴对称的闭曲线，求
∫Lx3y2ds

因为

f(−x,y)=(−x)3y2=−x3y2=−f(x,y)

所以 f 对 x 是奇函数，于是

∫Lx3y2ds=0
  • 若 L 是关于 x 轴对称的曲线，求
∫L(x2+y2)ds

因为

f(x,−y)=x2+(−y)2=x2+y2=f(x,y)

所以

∫L(x2+y2)ds=2∫L1(x2+y2)ds

其中 L1 取上半部分即可。

¶容易失败的情况

  • 把第一类和第二类曲线积分混了。第二类曲线积分和方向有关，不能这样直接套。
  • 只看函数奇偶性，不看曲线是否真的关于对应轴对称。
  • 对称轴看错了。关于 y 轴对称，就要检查 x 变号后的奇偶性；关于 x 轴对称，就要检查 y 变号后的奇偶性。
  • 把半边曲线记错。关于 y 轴时，通常取右半边 x≥0 ；关于 x 轴时，通常取上半边 y≥0 。

¶怎么记

记一句话：

第一类曲线积分先看曲线对称，再看函数对对应变量的奇偶性。

再补一句：

弧长不带方向，所以同号就翻倍，异号就相消。
