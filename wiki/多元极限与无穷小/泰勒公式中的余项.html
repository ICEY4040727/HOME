泰勒公式中的余项

  • WIKI
  • 多元极限与无穷小
  • 泰勒公式中的余项

¶核心问题

泰勒公式里的余项到底是什么？

很多时候我们会写

f(x)=f(a)+f′(a)(x−a)+f″(a)2!(x−a)2+⋯

然后注意力全放在前面几项，仿佛后面只是一个“可有可无的尾巴”。

但真正重要的是：

  • 泰勒公式不是“函数等于一个有限次多项式”
  • 它真正说的是“函数 = 多项式近似 + 误差”
  • 余项正是在告诉我们这个误差有多大

¶先把本体写完整

n 阶泰勒公式的完整形式是

f(x)=f(a)+f′(a)(x−a)+f″(a)2!(x−a)2+⋯+f(n)(a)n!(x−a)n+Rn(x)

记

Pn(x)=f(a)+f′(a)(x−a)+f″(a)2!(x−a)2+⋯+f(n)(a)n!(x−a)n

则

f(x)=Pn(x)+Rn(x)

所以余项 Rn(x) 的定义就是：

Rn(x)=f(x)−Pn(x)

也就是说：

余项就是“真实函数值”和“前 n 阶泰勒多项式近似值”的差。

¶余项在表达什么

它表达的是误差控制。

前面的泰勒多项式告诉你：

  • 我先用一个简单的多项式去近似复杂函数

余项告诉你：

  • 这个近似到底还差多少

所以如果没有余项，泰勒公式就只剩“猜一个多项式”；有了余项，它才是严格的分析结论。

¶为什么不能把余项直接忽略

因为有限阶泰勒公式不是说

f(x)=Pn(x)

而是说

f(x)=Pn(x)+Rn(x)

只有当你进一步知道

Rn(x)

足够小，并且小到不影响你当前的问题时，才可以在计算里把它压掉。

所以“忽略余项”这件事本身需要理由，而不是默认动作。

¶佩亚诺余项在说什么

最常见的一种写法是

f(x)=Pn(x)+o((x−a)n)(x→a)

这叫佩亚诺余项形式。

它的意思是

Rn(x)(x−a)n→0(x→a)

也就是说：

余项比 (x−a)n 还要小一个量级。

这说明前 n 阶多项式已经准确抓住了到 n 阶为止的主要结构，剩下误差更小。

¶例子

当 x→0 时，

ex=1+x+x22+o(x2)

这里的意思不是“后面没有项了”，而是：

  • 主导部分是
1+x+x22
  • 剩下的误差，比 x2 还小

所以如果你只比较到二阶，这个误差已经不会改变主导结构。

¶为什么有时写成 o(xn) ，有时像是应该写 o(xn+1)

这是一个常见困惑。

如果写成

f(x)=Pn(x)+o((x−a)n)

意思是余项比第 n 阶项还小。

如果函数更光滑，也常能写成更强的形式，例如

f(x)=Pn(x)+O((x−a)n+1)

或者某些教材直接写成

f(x)=Pn(x)+f(n+1)(ξ)(n+1)!(x−a)n+1

这就是拉格朗日余项形式。

所以：

  • o((x−a)n) 强调“比第 n 阶还小”
  • O((x−a)n+1) 或拉格朗日余项强调“误差大约是下一阶”

它们关注角度不同，但都在描述误差。

¶拉格朗日余项在说什么

若函数有更高阶导数，则常见写法是

Rn(x)=f(n+1)(ξ)(n+1)!(x−a)n+1

其中 ξ 在 a 和 x 之间。

这表示：

  • 误差确实和 (x−a)n+1 同量级
  • 系数不是固定在 a 点，而是取决于中间某个点 ξ

你可以把它理解成：

前 n 阶已经固定住以后，剩下的第一块误差，本质上落在第 n+1 阶上。

¶佩亚诺余项和拉格朗日余项怎么区分

¶佩亚诺余项

写法：

Rn(x)=o((x−a)n)

特点：

  • 强调“比第 n 阶更小”
  • 适合极限、阶数比较、主导项判断

¶拉格朗日余项

写法：

Rn(x)=f(n+1)(ξ)(n+1)!(x−a)n+1

特点：

  • 强调误差的具体形式
  • 适合估计误差大小、证明近似精度

¶余项为什么和“保留到哪一阶”直接相关

例如

ex−1−xx2

当 x→0 时，

ex=1+x+x22+o(x2)

代入后得到

ex−1−xx2=x22+o(x2)x2=12+o(1)

这里余项没有被“忘掉”，而是被严格控制成

o(x2)x2=o(1)

所以最后极限才稳。

这说明：

  • 要不要继续展开，不只看前面几项
  • 还要看余项在除法、比较阶时会不会被放大

¶放到二元函数里怎么理解

二元函数里写

f(x0+h,y0+k)=P2(h,k)+o(h2+k2)

意思不是“后面什么都没有了”，而是：

  • 二阶泰勒多项式已经抓住了到二阶为止的主要部分
  • 剩余误差相对于 h2+k2 来说更小

也就是

R(h,k)h2+k2→0((h,k)→(0,0))

这和一元里的余项思想完全一样，只是把比较对象从 |x−a|2 换成了二元小量的二阶尺度。

¶等价刻画

你可以把余项理解成下面三句话中的任意一句：

  • 余项是近似误差
  • 余项说明前面多项式近似到了什么精度
  • 余项决定你能不能合法地忽略后面的高阶部分

¶常见误解

  • 把余项当成“写不下去时随手补的东西”。
  • 看到泰勒展开就默认后面高阶项都能直接扔掉。
  • 不理解 o((x−a)n) 的意思，只把它当符号记。
  • 把“余项比第 n 阶小”误解成“余项等于 0”。
  • 不区分佩亚诺余项和拉格朗日余项的用途。

¶怎么记

记住一句话：

泰勒多项式负责近似，余项负责为这个近似兜底。

如果再加一句，就记：

能不能忽略后面的部分，不是靠感觉，而是靠余项的量级。
