泰勒展开

  • WIKI
  • 多元极限与无穷小
  • 泰勒展开

¶核心问题

泰勒公式在说什么？

这里最容易混淆的是：

  • 展开点是谁
  • 目标点是谁
  • 麦克劳林公式和泰勒公式是什么关系
  • 泰勒公式和泰勒级数是不是一回事

如果这些角色没有分开，看到

f(1)=f(0)+f′(0)+f″(0)2!+⋯

就会觉得奇怪：明明要求的是 1 点的函数值，为什么后面全是和 0 有关的信息。

¶泰勒公式真正说的是什么

泰勒公式不是在说：

函数在 x 处的值，只由 x 自己决定。

它说的是：

我想知道函数在目标点 x 处的值，但我先站在展开点 a ，利用函数在 a 处的导数信息，构造一个多项式去逼近 f(x) 。

所以泰勒公式里天然有两个不同角色：

  • 展开点 a
  • 目标点 x

¶定义

设函数 f(x) 在点 a 的附近有足够多阶导数，则它在点 a 处的 n 阶泰勒公式为

f(x)=f(a)+f′(a)(x−a)+f″(a)2!(x−a)2+⋯+f(n)(a)n!(x−a)n+Rn(x)

其中

Pn(x)=f(a)+f′(a)(x−a)+f″(a)2!(x−a)2+⋯+f(n)(a)n!(x−a)n

叫做 f 在点 a 处的 n 阶泰勒多项式。

所以更本质地说，泰勒公式就是

f(x)=Pn(x)+Rn(x)

也就是：

  • Pn(x) 负责给出主要近似
  • Rn(x) 负责表示误差

¶麦克劳林公式是什么

麦克劳林公式不是新的东西，它只是泰勒公式在展开点 a=0 时的特例。

把 a=0 代入上式，得到

f(x)=f(0)+f′(0)x+f″(0)2!x2+⋯+f(n)(0)n!xn+Rn(x)

这就叫麦克劳林公式。

所以：

  • 在任意点 a 展开，叫泰勒公式
  • 在 0 点展开，叫麦克劳林公式

本质完全一样，只是展开中心不同。

¶为什么要求 f(1) ，却会出现 f(0),f′(0),f″(0)

这是理解泰勒公式时最关键的一步。

先写麦克劳林公式：

f(x)=f(0)+f′(0)x+f″(0)2!x2+⋯+Rn(x)

这时公式里的 x 还是一个变量。

如果我们现在想求 f(1) ，只需要把 x=1 代进去：

f(1)=f(0)+f′(0)+f″(0)2!+⋯+Rn(1)

所以这里没有任何矛盾。

因为：

  • 0 是展开点
  • 1 是目标点

泰勒公式本来就是“用展开点的信息，表示目标点的函数值”。

¶为什么书上会写

Φ(1)=Φ(0)+Φ′(0)+Φ″(0)2!+⋯

书上这一步通常省略了中间过程。

真正完整的逻辑是先对一元函数 Φ(t) 在 t=0 处写麦克劳林公式：

Φ(t)=Φ(0)+Φ′(0)t+Φ″(0)2!t2+⋯+Rn(t)

然后再令

t=1

于是得到

Φ(1)=Φ(0)+Φ′(0)+Φ″(0)2!+⋯+Rn(1)

所以这里要区分：

  • 公式是在哪个点展开的：在 0 点
  • 最后要求的是哪个点的值：是 1 点

¶等价刻画

你可以把泰勒公式理解成下面三句话中的任意一句：

  • 用展开点 a 处的导数信息构造一个局部多项式近似
  • 把复杂函数在 a 附近按“阶”分层写出来
  • 用低次多项式抓住主要变化，把剩下部分放进余项

¶例子

¶例 1：在 0 点展开，但求的是 1 点的值

对

f(x)=ex

在 0 点作麦克劳林展开：

ex=1+x+x22!+x33!+⋯

若现在要求 e1 ，只要代入 x=1 ：

e=1+1+12!+13!+⋯

这正说明：

  • 展开点是 0
  • 目标点是 1

¶例 2：在一般点 a 处展开

若在点 a 附近展开，则

f(x)=f(a)+f′(a)(x−a)+f″(a)2!(x−a)2+⋯

如果你最后要求的是 f(a+h) ，就把 x=a+h 代进去，得到

f(a+h)=f(a)+f′(a)h+f″(a)2!h2+⋯

这里更容易看出：

  • 展开点是 a
  • 目标点是 a+h

¶余项是什么

余项 Rn(x) 表示：

用 n 阶泰勒多项式近似以后，还剩下多少误差。

所以泰勒公式不是“函数等于一个有限多项式”，而是：

函数 = 有限多项式近似 + 误差项

很多初学时的混乱，都来自把余项忽略得太早。

¶泰勒公式和泰勒级数不是一回事

这是另一个很常见的混淆。

¶泰勒公式

有限阶展开，带余项：

f(x)=Pn(x)+Rn(x)

¶泰勒级数

把阶数一直写到无穷：

∑k=0∞f(k)(a)k!(x−a)k

但写出这个级数，不代表它一定等于原函数。

所以学习时应先抓住：

  • 泰勒公式是有限阶近似公式
  • 泰勒级数是无穷级数对象

¶常见误解

  • 把展开点和目标点看成同一个东西。
  • 认为要求 f(1) ，公式里就必须只出现和 1 有关的量。
  • 把麦克劳林公式当成和泰勒公式完全不同的公式。
  • 把泰勒公式误认为“函数等于有限项多项式”。
  • 不区分“带余项的有限阶公式”和“无穷泰勒级数”。

¶怎么记

记住一句话：

泰勒公式是在展开点读取局部信息，再用它逼近目标点的函数值。

如果是麦克劳林公式，就再加一句：

麦克劳林公式只是把展开点固定成了 0 。
